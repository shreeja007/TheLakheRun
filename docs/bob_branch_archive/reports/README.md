# Codex implementation reports

After each **authorized** task, Codex creates a concise `TXXX_RESULT.md` here (using `REPORT_TEMPLATE.md`) and includes links to evidence stored in the repository or the handoff message. Do not create a report to imply an unstarted ticket was completed.

The Game Director sets the review outcome: `ACCEPTED`, `CHANGES REQUESTED`, or `REJECTED`, and updates `docs/10_DECISIONS.md` and `tasks/00_TASK_INDEX.md` as appropriate. Reports are implementation evidence, not authorization for the next task.
